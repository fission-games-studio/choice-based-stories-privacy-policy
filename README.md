# Privacy Policy — Choice-Based Stories

**Last updated: July 2026**

## Summary

Choice-Based Stories does not collect, store, transmit, or sell any personal data, browsing history, or user information to any external server. Everything the game does happens locally, on your own device.

## What the game does

Choice-Based Stories is a fully offline, single-player visual novel. It has no network component, no analytics, no advertising, and no in-app purchases. It does not communicate with any external server at any point.

## Save data

The game stores your save files and progress locally on your own device, using the standard save/load system provided by the Ren'Py engine. This data never leaves your device and is not accessible to us or to any third party.

## "How It's Gone" statistics screen

The game includes an optional in-game screen showing simulated statistics about story outcomes (for example, what percentage of a modeled sample of playthroughs reached a given ending). These numbers are generated in advance from an offline simulation and are **not** collected from real players — the game does not know or report anything about your own choices to us or to anyone else.

## Permissions

The Android version of this app may request the device's vibration permission, used only for optional haptic feedback during play. No other device permissions are requested, and no data is read from or written to any other app or service on your device.

## Children's privacy

This game contains mature themes intended for a general audience rated appropriately on its store listing. It does not knowingly collect any information from anyone, including children, because it does not collect information from anyone at all.

## Changes to this policy

If this policy ever changes (for example, if a future update adds an online feature), this page will be updated accordingly, and the "Last updated" date above will reflect the change.

## Contact

If you have questions about this policy, please open an issue on this repository.
